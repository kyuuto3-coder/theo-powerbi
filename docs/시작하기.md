# 처음부터 따라 하기 — Claude Code Desktop으로 Power BI 리포트 만들기

AI 도구를 한 번도 써 본 적이 없어도 됩니다. 아래 순서대로 **한 단계씩** 따라 하세요. (예상 소요: 처음 설정 20분, 이후 리포트 1개당 5~10분)

## 1단계. 프로그램 설치 (한 번만)
1. **Power BI Desktop** 설치
   - Windows의 **Microsoft Store**를 열고 `Power BI Desktop`을 검색해 **설치**합니다. (회사 PC에 이미 있으면 건너뜁니다.)
   - 설치 후 한 번 실행해 로그인합니다. 열린 창은 닫아도 됩니다.
2. **Claude Code Desktop** 설치
   - 브라우저에서 <https://claude.ai/code> 로 이동해 **Download for Windows**를 누르고 설치합니다.
   - 실행하면 로그인 화면이 뜹니다. 회사에서 안내받은 Claude 계정(Pro)으로 로그인합니다.
3. **이 폴더 내려받기**
   - <https://github.com/kyuuto3-coder/theo-powerbi> 에서 초록색 **Code** 버튼 → **Download ZIP**.
   - 내려받은 ZIP을 **문서** 폴더 등 기억하기 쉬운 곳에 **압축 해제**합니다. 폴더 이름이 `theo-powerbi-main`이면 그대로 두어도 됩니다.
   - ⚠️ 폴더 경로에 한글이 있어도 괜찮지만, OneDrive 동기화 폴더는 피하세요 (파일 잠김 오류가 날 수 있습니다).

## 2단계. 데이터 넣기
1. 압축을 푼 폴더 안의 **`rawdata`** 폴더를 엽니다.
2. 분석할 **엑셀(.xlsx)** 또는 **CSV(.csv)** 파일을 이 폴더에 복사합니다.
   - 여러 파일도 됩니다. 엑셀은 시트마다 표 하나씩 인식합니다.
   - 표는 **첫 행이 열 이름**이면 가장 좋습니다. 제목 행이 위에 몇 줄 있어도 대부분 자동으로 인식합니다.
   - 열 설명 시트(예: `Data Definition`)가 있으면 그대로 두세요. Claude가 참고합니다.

## 3단계. Claude Code Desktop에서 폴더 열기
1. **Claude Code Desktop**을 실행합니다.
2. 첫 화면에서 **Open folder**(폴더 열기)를 누르고, 2단계에서 데이터를 넣은 **폴더(압축 푼 폴더 전체)**를 선택합니다. `rawdata`가 아니라 그 **상위 폴더**입니다.
3. 화면 아래쪽에 채팅 입력창이 보이면 준비 완료입니다.
4. **모델 확인** — 입력창에 `/model` 이라고 치고 Enter를 누르면 모델 목록이 뜹니다. **Sonnet**(예: Claude Sonnet 5)을 선택하세요. Pro 요금제에서 가장 넉넉하게 쓸 수 있는 모델입니다. (Opus는 더 비싸고 빨리 한도에 닿습니다.)

## 4단계. 원하는 리포트 말하기
입력창에 **어떤 데이터로, 무엇을 보고 싶은지** 한국어로 씁니다. Enter로 보냅니다. 예시:

```
rawdata에 있는 판매 데이터로 대시보드 만들어줘.
1페이지: 총 매출, 주문 수, 평균 단가 카드 / 월별 매출 추이 / 지역별 매출 순위
2페이지: 제품별 상세 표
```

```
App Data.xlsx로 앱스토어 분석 리포트 만들어줘. 장르별 앱 수와 평균 평점, 가격대별 분포가 보이면 좋겠어.
```

참고할 그림이 있으면 **이미지 파일을 입력창에 끌어다 놓거나** 복사(Ctrl+C) 후 붙여넣기(Ctrl+V) 하고, "이 화면처럼 만들어줘"라고 쓰세요.

💡 잘 모르겠으면 그냥 `rawdata 데이터로 보기 좋은 대시보드 만들어줘` 라고만 써도 됩니다. Claude가 데이터를 보고 알아서 구성합니다.

## 5단계. Claude가 일하는 동안
- Claude가 **"Allow?"**(허용할까요?) 같은 확인 창을 띄우면 **Yes / Allow**를 누릅니다. 이 폴더 안의 스크립트를 실행하겠다는 뜻이며, 회사 데이터는 PC 밖으로 나가지 않습니다.
  - 매번 묻는 게 번거로우면 **"Yes, and don't ask again for this folder"**(이 폴더에서는 다시 묻지 않기)를 고르세요.
- Claude가 **질문**을 하면(예: "매출은 어느 열인가요?") 짧게 답합니다. 보통 0~2번입니다.
- 1~3분 뒤 Claude가 한국어로 **무엇을 만들었는지** 정리해 주고, 파일 위치를 알려 줍니다: `output/<이름>/<이름>.pbip`

## 6단계. Power BI에서 열기
1. 탐색기에서 `output/<이름>/` 폴더를 열고 **`<이름>.pbip`** 파일을 더블클릭합니다. Power BI Desktop이 열립니다.
2. 상단 **Home** 리본의 **Refresh**(새로 고침)를 누릅니다. 데이터가 읽히고 차트가 채워집니다.
3. **File > Save As** → 파일 형식 **Power BI files (*.pbix)** 로 저장합니다. 이 `.pbix` 파일을 공유하거나 게시하면 됩니다.

## 7단계. 고치기
Claude 채팅으로 돌아가서 말합니다.
```
2페이지 표를 매트릭스로 바꾸고, 1페이지 막대그래프는 상위 5개만 보여줘
```
```
"평균 단가" 카드 대신 "이익률" 카드를 넣어줘. 이익률 = (매출-원가)/매출
```
Claude가 다시 만들면 `.pbip`를 다시 열고(또는 열려 있으면 닫았다가 다시 열고) **Refresh** 합니다.

⚠️ **Power BI Desktop에서 직접 꾸미는 작업(색, 글꼴 등)은 Claude 수정이 모두 끝난 뒤** `.pbix`로 저장한 파일에서 하세요. Claude가 다시 만들면 `output` 안의 프로젝트는 덮어써집니다.

## 8단계. (선택) 직접 만드는 방법 배우기
리포트가 완성되면 Claude가 **"수동 제작 가이드도 만들어 드릴까요?"** 라고 묻습니다. **네**라고 답하면 `output/<이름>/manual-guide.md` 파일이 생깁니다. Power BI Desktop에서 같은 리포트를 손으로 만드는 순서가 메뉴 이름(영어)과 함께 적혀 있어, 직접 배우고 싶을 때 따라 하면 됩니다. 메모장이나 브라우저로 열어 보세요.

## 자주 묻는 질문
- **다른 사람이 만든 .pbip를 열었더니 "열을 찾을 수 없음" 오류가 나요.** 데이터 폴더 경로가 그 사람 PC 기준이라서 그렇습니다. **Home > Transform data > Edit parameters** → `DataFolder`에 내 PC의 `rawdata` 폴더 전체 경로를 넣고 **OK** → **Refresh**. (공유는 `.pbix`로 하는 게 편합니다.)
- **리포트 안 글자가 영어예요.** 의도된 동작입니다. 테이블·열·측정값·페이지 이름과 제목은 영어로 만들어집니다(Power BI 메뉴가 영어이고 공유하기 쉽도록). 한국어로 바꾸고 싶은 항목이 있으면 Claude에게 "제목만 한국어로 바꿔줘"라고 말하면 됩니다.
- **오류가 났어요.** Power BI 오류 창의 문구를 복사해서 Claude 채팅에 붙여 넣고 "이 오류 고쳐줘"라고 하세요.
- **한도에 도달했다고 나와요.** Pro 요금제는 5시간 단위로 사용량이 초기화됩니다. 잠시 후 다시 시도하고, 모델이 **Sonnet**인지 `/model`로 확인하세요.
- **데이터 파일을 바꿨어요.** 파일 이름·시트·열이 같으면 Power BI에서 **Refresh**만 누르면 됩니다. 열이 바뀌었으면 Claude에게 "데이터 파일 바꿨어, 다시 만들어줘"라고 하세요.
- **Claude가 rawdata 파일을 못 찾는대요.** 3단계에서 **상위 폴더**(README.md가 있는 폴더)를 열었는지 확인하세요.
- **이전 대화를 이어가고 싶어요.** Claude Code Desktop 왼쪽의 대화 목록에서 이전 세션을 누르면 됩니다. 새 리포트를 만들 때는 **새 대화**를 시작하는 것이 토큰을 아낍니다.
- **회사 데이터가 외부로 나가나요?** 데이터 파일 자체는 PC에서만 처리됩니다. Claude에게는 열 이름·형식·몇 개의 샘플 값만 요약되어 전달됩니다.
